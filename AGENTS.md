# AGENTS.md — instructions for LLM coding agents

**Before reading any other file, read [`docs/MAP.md`](docs/MAP.md).** It is a ~2-minute index of every feature, a symptom→file table, the data model, a glossary and the invariants. Then open only the code blocks it points to, using `rg "@map:<tag>" src`.

Rules
1. Edit `src/`. Never hand-edit `dist/` (generated by `node tools/build.mjs`).
2. If you add, rename or remove an `@map:` anchor, update `docs/MAP.md` in the same change (`node tools/check-map.mjs` must pass).
3. Read `docs/DESIGN-NOTES.md` before changing behavioural rules (3-item cap, no-guilt rollover, Now card).
4. This repository is **public**. Never commit personal data, tokens/credentials, user backups (`*backup*.json`) or e-mail addresses. Use a noreply git identity.
5. Keep the font family name `DailyBrush` and ship the OFL licence (see `assets/fonts/README.md`).
6. After behaviour changes: `node tools/build.mjs` and `python3 tests/smoke.py`.
