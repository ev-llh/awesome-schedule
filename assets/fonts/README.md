# Fonts

`dailybrush-subset.woff2` is a **subset of Bakudai (莫大毛筆字體)**, regenerated by `tools/subset-font.py`.

- Upstream: https://github.com/max32002/bakudaifont — Copyright (c) 2020 Chun yu Yao; based on the Kouzan Brush Font (衡山毛筆フォント) by Aoyagi Kouzan.
- Licence: SIL Open Font License 1.1 — full text in `LICENSE-OFL-1.1.txt` (must stay with the font).
- Because a subset is a *Modified Version*, OFL §3 forbids the Reserved Font Name "Bakudai" as its primary name. The font's family/full/PostScript names are therefore rewritten to **DailyBrush**; copyright and licence records in the name table are preserved. Do not rename it back.
- Coverage: ASCII + Big5 punctuation + Big5 level-1 (~5.4k common Traditional characters) + every non-ASCII character used in `src/`. Anything else (rare, Simplified, emoji) falls back to system serif fonts. For wider coverage run the subset script with `--level2` (larger file).
- The embedded @font-face is limited to CJK ranges (`unicode-range` in `tools/build.mjs`): Bakudai's Latin glyphs are very wide and loosely spaced, so English text uses the serif fallback in the `--serif` stack.
- The full font is not stored here (≈14 MB TTF). Get it from the upstream repo.
